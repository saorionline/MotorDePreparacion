# Code Style

* **Regla de Validación Temprana (*Fail-Fast*):** La capa de preparación y transformación (Python) debe actuar como un guardián rígido. Si se detecta la ruptura de un contrato de datos o la violación de una invariante (precisión de enteros, rangos de $2^{53}-1$, discrepancia de salidas esperadas), el script debe reportar el fallo por `sys.stderr` y terminar inmediatamente de forma ruidosa con `sys.exit(1)`.


* **Visualización Declarativa:** Las especificaciones de reporte e interfaz gráfica (e.g., Vega-Lite JSON) deben ser declarativas y desvinculadas de la lógica del sistema. No se debe programar lógica imperativa ni transformaciones dentro de los componentes visuales; estas deben ser resueltas previamente en las fases de transformación o agregaciones SQL.


* Use camelCase file naming.
* Prefer relative imports and mixed exports.
